# 월화(月花) 전쟁 및 약탈 세부 규칙

> 이 문서는 [RULES.md](RULES.md) 제3장(약탈 및 거점)과 제4장(PvP 및 전쟁)의 세부 운영 절차다.
> 규칙의 효력은 RULES.md에 있으며, 이 문서와 다르면 RULES.md를 따른다.

- 문서 버전: v1.0

## 1. 한눈에 보는 약탈 가능 여부

| 대상 | 평시 | 전쟁 시간 (참가자, 전쟁 구역 안) | 근거 |
|---|---|---|---|
| 보호구역 (스폰 반경 300블록, 공지 지역) | ⛔ 불가 | ⛔ 불가 | 제13조 |
| 신규 유저 구조물 (첫 접속 7일 이내) | ⛔ 불가 | 해당 없음 (명단 등록 불가) | 제14조 |
| 중립 유저 등록 거점 | ⛔ 불가 | ⛔ 불가 (제3자 보호) | 제19조, 제39조 |
| 클랜 등록 거점 (전쟁 상대) | ⛔ 불가 | ✅ 파괴·약탈 가능 | 제16조 |
| 클랜 등록 거점 (전쟁 무관 클랜) | ⛔ 불가 | ⛔ 불가 | 제19조 |
| 참전 동맹 등록 거점 | ⛔ 불가 | ✅ 파괴·약탈 가능 | 제37조 |
| 미등록 구조물 | ✅ 상자 약탈 + 출입구 1곳 파괴 | ✅ 평시와 같음 (제15조 범위) | 제15조 |
| 엔더 상자 내용물 | ⛔ 불가 | ⛔ 불가 | 제15조, 제16조 |

## 2. 전쟁 진행 순서

```
[신청] ──24시간 안에 응답──▶ [수락/거절/무응답=수락]
   │
   ▼
[운영진 승인 공지] ── 전쟁 구역 좌표, 시작 시각 공지
   │   · 이때부터: 거점 변경 금지, 가입·탈퇴 금지, 물자 위탁 금지
   │
   ▼  (24~72시간 준비)
[명단 마감] ── 시작 6시간 전
   │
   ▼
[전쟁 시간] ── 19:00~23:00 중 정각 시작, 2시간
   │   · 항복 선언 시 즉시 종료
   │
   ▼
[철수 시간] ── 30분, 전투·약탈 금지
   │
   ▼
[보복 금지 기간] ── 72시간
       · 가입·탈퇴 금지, 거점 변경 금지, 물자 위탁 금지 유지
       · 전쟁 관련 신고 마감
```

### 2-1. 신청 조건 확인 (제22조)

| 확인 항목 | 기준 |
|---|---|
| 클랜 등록 기간 | 7일 이상 |
| 등록 거점 | 있음 |
| 진행·대기 중인 전쟁 | 없음 (공격·방어 모두) |
| 같은 상대 재신청 | 이전 전쟁 종료 후 72시간 경과, 취소했다면 7일 경과 |
| 상대의 이번 주 방어 횟수 | 2회 미만 |
| 신청자 | 수장 또는 부수장 |

### 2-2. 신청 양식

디스코드 **#전쟁-신청** 채널에 아래 양식을 그대로 복사해 작성한다.

```
[전쟁 신청]
신청 클랜:
상대 클랜:
신청자(수장/부수장):
희망 시작 일시(19:00~23:00 정각, 승인 후 24~72시간):
참전 동맹(없으면 '없음'):
신청 클랜 등록 클랜원 수:
```

### 2-3. 응답 양식

```
[전쟁 응답]
응답 클랜:
응답자(수장/부수장):
응답: 수락 / 거절(이번 7일 거절권 사용)
희망 시작 일시(선택):
참전 동맹(없으면 '없음'):
```

### 2-4. 명단 양식 (시작 6시간 전 마감)

```
[전쟁 명단]
클랜:
본 클랜 참가자: 닉네임1, 닉네임2, ...
동맹 참가자(동맹 클랜명): 닉네임1, ...
```

인원 상한 계산 (제25조):
- 신청 측 총 참가 인원 ≤ 방어 측 **등록 클랜원 수** × 2
- 각 진영 동맹 참가 인원 ≤ 그 진영 본 클랜 참가 인원

> 예: 방어 클랜 등록 클랜원 6명 → 신청 측은 동맹 포함 최대 12명. 신청 측 본 클랜 참가자가 7명이면 동맹은 최대 5명(합계 12명 상한).

## 3. 전쟁 구역 계산 (제26조)

1. 각 등록 거점의 범위를 사방으로 100블록씩 넓힌 사각형이 그 거점의 전쟁 구역이다.
2. 양측과 참전 동맹의 거점마다 전쟁 구역이 생긴다. 거점 사이의 이동 경로는 전쟁 구역이 아니다.
3. 높이 제한은 없다. 같은 X·Z 범위의 지하와 하늘도 포함한다.
4. 보호구역과 겹치는 부분은 보호구역이다.

> 예: 거점 범위가 (1000, 2000) ~ (1150, 2150)이면 전쟁 구역은 (900, 1900) ~ (1250, 2250)이다.

거점 사이 이동 경로에서의 전투:
- 전쟁 시간 동안 **참가자끼리**는 전쟁 구역 밖에서도 전투할 수 있다.
- 전쟁 구역 밖에서의 **블록 파괴와 약탈**은 테러다 (제18조).

## 4. 전쟁 중 행동 기준

### 4-1. 허용

- 상대 거점 침입, 블록 파괴, 저장 시설 약탈
- TNT (동시 점화 64개 이하), 전투·돌파용 용암·물·불
- 크리퍼·몬스터 유인, 함정 설치
- 엔드 수정, 리스폰 정박기 폭발
- 엔더 진주, 네더 차원문 이동
- 사망 후 침대·리스폰 정박기 부활
- 오프라인 상대의 거점 약탈
- 기만 전술 (위장 거점, 가짜 정보 흘리기, 매복)

### 4-2. 금지 ⛔

- 위더 소환
- 용암 캐스팅으로 건물 덮기, 거점 전체를 태우는 방화
- 동시 점화 TNT 64개 초과, 그 밖의 렉 유발 공격
- 전쟁 구역 밖 파괴·약탈
- 명령어 텔레포트 (홈, 텔레포트 요청, 랜덤 이동)
- 전투 중(15초 이내) 고의 접속 종료
- 공식 항복 선언 후 공격
- 비참가자의 전쟁 구역 진입과 개입
- 철수 시간 이후의 전투·약탈

### 4-3. 철수 시간 (30분)

- 공격 측은 상대 거점 범위 밖으로 나간다.
- 이미 연 상자의 물자를 챙겨 나가는 것은 허용한다. 새로 파괴하거나 상자를 여는 것은 금지한다.
- 상대 거점 안에 설치한 용암·물·불은 철수 시간 안에 치운다. 치우지 않으면 테러로 본다.
- 방어 측은 자기 거점 안에 남은 공격 측 유저를 공격할 수 없다. 30분이 지나도 남아 있으면 신고한다.

## 5. 항복·취소·중단

| 상황 | 누가 | 결과 |
|---|---|---|
| 시작 전 취소 | 신청 측 수장·부수장 | 전쟁 취소. 같은 상대 7일 재신청 불가 |
| 시작 전 방어 측 포기 | 방어 측 | 취소할 수 없다. 전쟁 시간에 즉시 항복을 선언할 수 있다 |
| 전쟁 중 항복 | 양측 수장·부수장 | 즉시 전쟁 시간 종료, 철수 시간 시작 |
| 서버 장애 | 운영진 | 중단. 남은 시간이 1시간 이상이면 72시간 안에 재개 일정을 잡는다 |
| 중대 위반 발생 | 운영진 | 중단 후 조사. 재개 여부는 운영진이 결정 |

항복 선언 양식 (#전쟁-진행 채널):
```
[항복] 클랜: / 선언자: / 선언 시각:
```

## 6. 운영진 체크리스트

### 승인 전
- [ ] 신청 조건 6가지 확인 (2-1)
- [ ] 양측 거점 등록 상태와 좌표 확인
- [ ] 담당 운영진의 기피 사유 확인 (제51조)
- [ ] 시작 시각이 19:00~23:00 정각, 승인 후 24~72시간 사이인지 확인

### 승인 공지
- [ ] 양측 클랜, 참전 동맹, 시작 시각, 전쟁 구역 좌표 공지
- [ ] 가입·탈퇴·거점 변경 잠금 기록

### 명단 마감 후
- [ ] 인원 상한 확인 (2-4)
- [ ] 신규 유저, 중립 유저 포함 여부 확인
- [ ] 같은 IP·가족 계정이 양쪽에 있는지 확인

### 전쟁 중
- [ ] 운영진 1인 이상 관전 대기 (가능한 경우)
- [ ] 보호구역, 제3자 거점 주변 확인
- [ ] 항복 선언 확인

### 종료 후
- [ ] 전쟁 기록 채널에 결과(종료 사유, 시각) 기록
- [ ] 72시간 동안 접수된 신고 처리
- [ ] 잠금 해제 일시 공지

## 7. 기능 구현 분류

월화 서버에 아직 없는 기능은 아래와 같이 운영한다. 플러그인이 도입되면 이 표와 CHANGELOG.md를 함께 고친다.

| 기능 | 현재 운영 | 자동화에 필요한 것 | 관련 조항 |
|---|---|---|---|
| 거점 등록·보호 | `[수동]` 디스코드 등록 + 운영진 기록 | 영역 보호 플러그인 | 제12조 |
| 보호구역 PvP·파괴 차단 | `[수동]` 신고와 기록 확인 | 영역 보호 플러그인 | 제13조 |
| 신규 유저 보호 | `[수동]` 첫 접속일 확인 | 신규 보호 플러그인 | 제14조 |
| 전쟁 신청·승인 | `[수동]` 디스코드 채널 | 전쟁 관리 플러그인 또는 디스코드 봇 | 제22조~제24조 |
| 전쟁 시간 동안만 상대 거점 보호 해제 | `[수동]` 운영진이 시작·종료 시 보호 해제·복구 | 전쟁 관리 + 영역 보호 연동 | 제16조 |
| 전투 중 접속 종료 처벌 | `[수동]` 영상·기록 판정 | 전투 태그 플러그인 | 제28조 |
| 전쟁 중 텔레포트 차단 | `[수동]` 기록 판정 | 전투 태그 또는 명령어 제한 플러그인 | 제30조 |
| 핵 탐지 | `[수동]` 관전·영상 | 안티치트 플러그인 | 제40조 |
| 블록·상자 기록 | — | 블록 로그 플러그인 (예: CoreProtect) | 제42조, 제55조 |
| 운영진 권한 전환 | `[수동]` 자율 | 권한 관리 플러그인 | 제51조 |

> **블록 로그 플러그인은 도입을 강하게 권장한다.** 약탈과 테러의 구분, 복구, 허위 신고 판별이 모두 이 기록에 달려 있다.
