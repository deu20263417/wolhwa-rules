# 월화(月花) 제재 기준 및 처벌표

> 이 문서는 [RULES.md](RULES.md) 제10장(제59조~제62조)의 세부 기준이다. 조항 번호는 모두 RULES.md 기준이다.

- 문서 버전: v1.1
- 홈페이지의 제재표는 아래 처벌표의 기본 단계로 **1차·2차·3차 제재를 자동 계산**해 보여준다.

---

## 1. 제재 단계 (제59조)

| 단계 | 내용 | 확인 인원 (제52조) |
|---|---|---|
| 1단계 | 구두 경고 | 운영진 1인 |
| 2단계 | 공식 경고 (기록) | 운영진 1인 |
| 3단계 | 1일 정지 | 운영진 2인 |
| 4단계 | 3일 정지 | 운영진 2인 |
| 5단계 | 7일 정지 | 운영진 2인 |
| 6단계 | 30일 정지 | 운영진 2인 |
| 7단계 | 영구 정지 | 운영진 2인 이상 + 총괄 운영자 |

제재와 별도로 **회수**(제46조), **원상 복구**, **자격 상실**(제39조) 같은 부가 조치가 함께 붙을 수 있다. 부가 조치는 단계에 포함되지 않는다.

---

## 2. 단계 계산 방법

```
최종 단계 = 기본 단계 + 재범 가산 + 가중 − 감경
```

1. **기본 단계**: 아래 처벌표의 값.
2. **재범 가산** (제61조): 180일 안에 같은 조항을 다시 어기면 직전에 받은 단계 + 1. (기본 단계보다 직전 단계가 높으면 직전 단계를 기준으로 한다.)
3. **경고 누적** (제61조 제3항): 180일 안에 2단계를 3회 받았다면 다음 제재는 최소 3단계.
4. **가중·감경** (제62조): 각각 최대 2단계. 최종 단계는 1단계보다 낮아지지 않고 7단계보다 높아지지 않는다.
5. **여러 조항에 걸친 한 행위**: 가장 높은 기본 단계 하나를 적용하고, 필요하면 가중 +1을 더한다. 조항마다 따로 합산하지 않는다.
6. 🚨 **중대 위반**(제60조)은 기본 7단계이며 감경하지 않는다. 다만 고의가 없었다는 것이 증거로 확인되면 운영진 2인 이상이 협의해 5단계까지 낮출 수 있다.

## 2-1. 1차·2차·3차 제재와 영구 제재 조건

| 차수 | 기준 | 비고 |
|---|---|---|
| 1차 | 처벌표의 기본 단계 | 가중·감경 적용 |
| 2차 | 180일 안에 같은 조항 재위반: 직전 단계 + 1 | 제61조 제2항 |
| 3차 | 180일 안에 같은 조항 세 번째: 직전 단계 + 1 | 최소 3단계 (제61조 제3항) |

**영구 정지(7단계)는 다음 경우에만 적용한다.**
1. 🚨 중대 위반(제60조)이 증거로 확인된 경우
2. 재범 가산으로 단계가 7단계에 이른 경우
3. 6단계(30일 정지)를 받은 뒤 180일 안에 4단계 이상 위반을 다시 한 경우

어느 경우든 운영진 2인 이상과 총괄 운영자의 승인이 필요하다 (제52조 제3항).

| 분류 | 판정 기준 | 예외 (제재하지 않음) | 필요한 증거 |

| 핵·프로그램 | 운영진 2인 이상이 증거 확인 | 허용 모드 목록의 모드 (제41조) | 안티치트 기록, 영상, 관전 기록 |
| 버그·경제 | 반복 횟수, 이익 규모, 신고 여부 | 1회 확인 후 즉시 신고 (제44조 제4항) | 거래·블록 기록 |
| 신고·운영 | 고의성, 조작 여부 | 착각한 신고 (제58조 제3항) | 원본 영상 파일, 서버 기록 |

신고는 디스코드 신고 티켓으로 하며, 사건 후 7일 안(전쟁 관련은 종료 후 72시간 안)에 한다 (제54조).

## 3. 가중 사유와 감경 사유

### 가중 사유 (+1단계씩, 최대 +2)
- 미리 계획했거나 여러 번 반복했다
- 피해자가 3명 이상이다
- 증거를 지우거나, 조사에서 거짓말을 했다
- 회수 대상을 팔거나 넘겨 없앴다 (제46조 제2항)
- 운영진이 멈추라고 한 뒤에도 계속했다
- 다른 유저나 부계정을 동원했다
- 위반자가 운영진이다 (제53조, 권한 회수 별도)

### 감경 사유 (−1단계씩, 최대 −2)
- 적발 전에 스스로 신고했다
- 180일 안에 제재 기록이 없고 피해가 작다
- 운영진이 요청하기 전에 원상 복구하거나 물자를 돌려줬다
- 고의가 없었다는 것이 기록으로 확인된다
- 조사에 성실히 협조했다

## 5. 계산 예시

**예 1.** 평시에 미등록 구조물을 털면서 벽을 크게 부순 유저 (R-1), 180일 안에 R-1 기록 1회(2단계), 바로 원상 복구함.
- 기본 2단계 → 재범으로 직전 2단계 + 1 = 3단계 → 자진 원상 복구 감경 −1 → **2단계(공식 경고) + 원상 복구**

**예 2.** 전쟁 중 홈 명령어로 거점에 돌아가 방어한 유저 (W-7), 첫 위반.
- 기본 2단계 → 가중·감경 없음 → **2단계(공식 경고)**

**예 3.** 중립 유저가 전쟁 직전 클랜 물자를 자기 거점에 보관 (N-1), 맡긴 클랜원 (W-6).
- 중립 유저: **3단계 + 중립 자격 상실**
- 맡긴 클랜원: 기본 4단계, 클랜원 2명이 함께 옮김(다른 유저 동원) +1 → **5단계(7일 정지) + 물자 원위치**

**예 4.** X-ray 리소스팩 사용이 영상과 블록 기록으로 확인됨 (H-1).
- 🚨 중대 위반 → **7단계(영구 정지) + 얻은 광물 전부 회수**
