# 신고 및 문의 안내

> 신고와 이의제기의 효력은 전체 규칙 제9장(제54조~제58조)에 있다. 이 문서는 절차를 쉽게 정리한 안내다.

## 1. 어디로 신고하나요

| 상황 | 접수처 | 기한 |
|---|---|---|
| 규칙 위반 (테러, 핵, 사기 등) | 디스코드 신고 티켓 | 사건 후 7일 안 |
| 전쟁 중 위반 | 디스코드 신고 티켓 | 전쟁 종료 후 72시간 안 |
| 서버 오류로 아이템 손실 | 디스코드 신고 티켓 (복구 신청) | 손실 후 7일 안 |
| 버그 발견 | 디스코드 버그 신고 채널 | 발견 즉시 |
| 제재에 대한 이의제기 | 디스코드 신고 티켓 (이의제기) | 제재 통보 후 7일 안, 1회 |
| 운영진의 위반 | 운영진 신고 티켓 (총괄 운영자 직접 검토) | 사건 후 7일 안 |

공개 채팅이나 공개 채널에 신고 내용을 올리지 마세요. 공개 저격은 제재 대상이 될 수 있습니다 (제54조 제1항).

## 2. 신고 양식

아래 양식을 복사해 티켓에 붙여 넣으세요.

```
[신고]
대상 닉네임:
일시 (예: 2026-11-19 21:30):
좌표 (예: X 1024 / Y 64 / Z -512):
상황 설명:
관련 조항 (모르면 비워도 됩니다):
증거: 영상 / 스크린샷 / 채팅 기록
```

## 3. 증거 준비

- [ ] 시간이 보인다 (화면 시계, 채팅 시각, 영상 녹화 시각)
- [ ] 좌표가 보인다 (F3 화면)
- [ ] 편집하지 않은 원본이다. 운영진이 원본 파일을 요청할 수 있다
- [ ] 상대의 닉네임이 보인다

서버 기록(블록·상자·채팅 기록)이 가장 우선합니다. 영상이 서버 기록과 다르면 서버 기록을 따릅니다 (제55조). 조작한 증거를 내면 중대 위반입니다 (제58조 제2항).

## 4. 처리 순서

1. **접수**: 운영진이 티켓을 확인한다.
2. **조사**: 서버 기록과 증거를 확인한다. 필요하면 관련 거점의 약탈을 임시로 멈춘다 (제56조 제2항).
3. **안내**: 접수 후 72시간 안에 결과나 진행 상황을 알린다 (제56조 제1항).
4. **제재와 회수**: 위반이 확인되면 근거 조항과 단계를 알리고, 부당하게 얻은 물자를 회수해 돌려준다.

## 5. 이의제기

- 제재 통보 후 7일 안에 한 번 할 수 있다.
- 처음 제재한 운영진이 아닌 다른 운영진이 검토하고 72시간 안에 결과(유지, 감경, 취소)를 알린다.
- 이의제기 중에도 제재는 그대로 진행된다.
- 새로운 증거가 나오면 기한이 지나도 다시 검토를 요청할 수 있다 (제57조).

## 6. 하지 말아야 할 것

- 고의로 사실이 아닌 내용을 신고하는 것 (제58조 제1항)
- 영상·스크린샷을 짜깁기하는 것 (제58조 제2항)
- 같은 내용을 여러 번 문의해 업무를 방해하는 것 (제50조, 제53조)
